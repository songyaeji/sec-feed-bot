# 3DEXPERIENCE — OS 명령 주입

**3DEXPERIENCE** 플랫폼 Station Launcher App에서 **OS 명령 주입** 취약점이 발견됐다. R2023x~R2026x 버전이 영향받으며, 미인증 공격자가 임의 명령을 서버에서 실행할 수 있다.

## 타임라인

- 2026-11-16 [NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-19732) — CVE-2026-19732 CVSS 9.9 공개, Station Launcher App OS 명령 주입 확인
- 2026-11-16 [NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-77033) — CVE-2026-77033 CVSS 9.9 공개, 동일 취약점 추가 확인
