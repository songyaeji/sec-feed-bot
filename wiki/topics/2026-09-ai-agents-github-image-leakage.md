# AI 코딩 에이전트 — GitHub 내부 이미지 1만3천 건 공개 노출

**AI 코딩 에이전트**들이 코드 리뷰용 스크린샷을 공개 GitHub 저장소에 자동 업로드하면서 300개 이상 기관의 개발자로부터 내부 이미지 1만3천여 건이 노출됐다. 청구 기록, 미공개 기능, 설정 정보 등 민감 데이터가 포함되었다.
