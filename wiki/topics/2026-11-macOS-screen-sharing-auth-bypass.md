# Apple macOS — Screen Sharing 인증 우회 취약점

Apple macOS의 Screen Sharing 서비스에 부적절한 인증 처리 취약점이 발견됐다. 네트워크에 연결된 공격자가 유효한 자격증명 없이 Screen Sharing에 인증할 수 있어 원격 기기 접근이 가능하다.
