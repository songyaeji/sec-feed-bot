마이크로소프트 10월 2026 패치 화요일에서 1,413개의 보안 결함을 수정했으며, 이 중 한 개는 실제 악용 중, 두 개는 공개 공개된 제로데이를 포함한다. 기록적인 규모의 패치이다. Windows 1,102개, Office 134개, Developer Tools 61개, SharePoint Server 36개, SQL Server 22개 포함.
