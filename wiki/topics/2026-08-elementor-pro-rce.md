# Elementor Pro — 미인증 원격코드 실행 (CVE-2026-32475)

WordPress 페이지 빌더 플러그인 **Elementor Pro**의 Forms 모듈 파일 업로드 기능에서 중대 취약점이 발견됐다. 미인증 공격자가 PHP 파일을 비롯한 위험한 파일 형식을 제한 없이 업로드하여 원격 코드 실행(RCE)이 가능하다. CVSS 9.0으로 평가되며 광범위 배포된 플러그인 대상이라 실제 악용 가능성이 크다.
