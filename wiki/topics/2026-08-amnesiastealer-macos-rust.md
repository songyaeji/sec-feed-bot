**AmnesiaStealer**라는 Rust 기반의 새로운 macOS 정보탈취 악성코드가 발견됐다. **Chromium 웹브라우저 세션 탈취**가 주 목표이며, 가짜 GitHub 다운로드 페이지("Download for macOS")와 **ClickFix 루어**를 통해 다단계 배포된다.
