# GitHub Actions Mini Shai-Hulud 캠페인 재감염

**actions-cool** 오픈소스 GitHub Actions 저장소 2건이 9월 재차 접근 가능하게 되어 미니 샤이-훌루드(**Mini Shai-Hulud**) 악성코드를 다시 실행하기 시작했다. 5월 2026 초기 침해 이후 몇 개월 만에 취약점이 재노출되면서 공급망 위협이 계속되고 있다.

## 타임라인

- 2026-05 — 초기 Mini Shai-Hulud 캠페인으로 actions-cool 저장소 침해
- 2026-09-25 [The Hacker News](https://thehackernews.com/2026/09/compromised-github-actions-came-back.html) — 재차 악성코드 실행 보도
