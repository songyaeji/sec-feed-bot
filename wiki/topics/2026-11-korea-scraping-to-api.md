개인정보보호위원회와 관계부처가 금융회사·핀테크·세무·건강관리 서비스 사업자들이 공공기관 홈페이지에서 개인정보를 무단 추출하는 '스크래핑(Scraping)' 관행을 개선하기로 결정했다. 2027년부터 API(응용프로그래밍 인터페이스) 등 안전한 개인정보 전송체계로 단계적 전환할 계획이다.

## 타임라인

- 2026-11-26 [개인정보보호위원회](https://www.dailysecu.com/news/articleView.html?idxno=209779) — 2027년부터 공공기관 개인정보 전송을 스크래핑에서 API 기반 방식으로 단계적 전환 추진, 개인정보 유출·오남용 위험 감소
