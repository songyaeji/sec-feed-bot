# Elementor WordPress 플러그인 — CSRF로 관리자 계정 생성 취약점

WordPress 페이지 빌더 플러그인 **Elementor**에서 교차 사이트 요청 위조(CSRF) 취약점이 발견됐다. 미인증 공격자가 피싱된 링크를 통해 임의의 사용자를 관리자 계정으로 승격시킬 수 있다. 광범위 배포 플러그인 대상 공격이 용이하다.
