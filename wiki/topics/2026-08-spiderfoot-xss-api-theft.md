**SpiderFoot** 위협 인텔리전스 및 OSINT 도구의 상관 제목 HTML 이스케이프 부족으로 인한 크로스사이트 스크립팅(XSS) 취약점. 외부 소스의 서버 배너, 메타데이터로부터 임의 이벤트 핸들러를 삽입하여 사용자 브라우저에서 스크립트 실행 및 API 키 탈취 위험 (CVSS 9.3).
