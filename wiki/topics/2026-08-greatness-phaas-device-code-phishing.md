상용 **Phishing-as-a-Service(PhaaS)** 툴킷 **Greatness**가 **Device Code Phishing** 기능을 추가했다. OAuth 2.0 Device Authorization Grant를 악용하여 Multi-Factor Authentication(MFA)을 우회하고 사용자 계정을 탈취한다. AitM(adversary-in-the-middle) 자격증명 피싱도 지원하며, 클라우드 계정 타겟 공격의 신규 위협으로 부상했다.
