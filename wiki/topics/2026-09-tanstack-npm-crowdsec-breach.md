5월 TanStack **npm** 패키지 공급망 공격이 보안 회사 **CrowdSec** 직원의 GitHub 계정도 침해했음이 드러났다. 공격자가 퇴사 직원의 GitHub 접근 권한을 방치한 틈을 타 CrowdSec의 프라이빗 저장소 170개를 복사했다. 공급망 공격이 서드파티 보안 기업까지 연쇄 피해를 입힌 사례다.

## 타임라인

- 2026-05-22 [추정] — 악성 TanStack npm 패키지 배포, CrowdSec 직원 노트북 침해
- 2026-09-18 [CrowdSec 자체 공지] — 170개 GitHub 저장소 복사 발각
- 2026-09-19 [The Hacker News](https://thehackernews.com/2026/09/crowdsec-says-tanstack-npm-attack-led.html) — CrowdSec 피해 내용 상세 보도
