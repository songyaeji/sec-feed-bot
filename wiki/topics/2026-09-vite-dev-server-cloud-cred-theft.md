# Vite 개발 서버 노출 대규모 스캔 캠페인 AWS·Azure 자격증명 탈취

대규모 스캔 캠페인이 인터넷 노출 **Vite** 개발 서버를 대상으로 자동화된 자격증명 탈취를 벌이고 있다. AWS와 Microsoft Azure 인스턴스의 클라우드 인증 정보, 설정 파일, 인프라 상태 파일을 노리는 공격이다. F5 Labs가 자세히 분석했다.
