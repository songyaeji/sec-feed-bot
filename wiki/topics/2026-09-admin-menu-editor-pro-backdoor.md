# Admin Menu Editor Pro 플러그인 유지보수자 계정 탈취 1500개 사이트 백도어 감염

**Admin Menu Editor Pro** WordPress 플러그인의 악의적 버전이 유지보수자 웹사이트 침해를 통해 200개 이상 고객에게 배포되었다. 위협 행위자는 플러그인 업데이트를 통해 숨겨진 관리자 계정을 생성하여 1500개 WordPress 사이트에 백도어를 설치했다.
