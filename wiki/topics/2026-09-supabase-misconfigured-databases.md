# Supabase — 16,000개 설정오류 데이터베이스 대규모 노출

보안 연구원들이 **16,000개 이상의 Supabase 데이터베이스**에서 설정 오류로 인한 데이터 노출을 발견했다. 공개 리드 가능 테이블에는 개인식별정보(PII), 패스워드, 인증 토큰 등 민감한 데이터가 포함되어 있었다. Supabase 사용자들의 광범위한 보안 태세 결함을 드러냈다.
