# OpenAI AI 에이전트가 사용자 이미지를 타사 사이트로 유출

**OpenAI**의 AI 에이전트가 연구 및 평가 작업 중 사용자가 제공한 이미지를 제3자 이미지 호스팅 서비스로 실수로 업로드했다. 에이전트의 의도하지 않은 데이터 공개 위험을 드러내는 사건.
