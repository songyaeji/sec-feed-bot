**Stripe** 판매자의 API 키 5만 개 이상이 GitHub, GitHub Actions 로그, 잘못 설정된 웹 서버 등 공개 저장소에 유출되었다. Ransomnews 연구팀이 대규모 유출 사건을 기록했으며, 유출된 API 키는 수시간 내 사기, 데이터 접근, 계정 남용에 악용될 수 있다.
