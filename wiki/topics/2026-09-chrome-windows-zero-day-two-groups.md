# Chrome/Windows 제로데이, 중국 2개 위협 그룹이 악용

Volexity 분석에 따르면 두 개의 중국 연결 위협 그룹이 동일한 Google Chrome 및 Microsoft Windows 제로데이 익스플로잇 체인을 9월 1일부터 거의 동시에 NGO를 표적으로 악용했다. UTA0560은 JavaScript 백도어 **GRIMWEDGE**를 배포했고, 다른 그룹은 별도의 백도어를 배포했다.
