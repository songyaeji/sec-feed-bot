# Clockinator Lite WordPress 플러그인 — SQL 인젝션 미인증 공격

Clockinator Lite WordPress 플러그인 1.1.0 이전 버전에 SQL 인젝션 취약점이 존재한다. 미인증 사용자가 사용자 지정 테이블 명을 입력해 임의의 데이터베이스 테이블에서 데이터를 삭제하거나 민감한 정보(비밀번호 해시 등)를 추출할 수 있다.
