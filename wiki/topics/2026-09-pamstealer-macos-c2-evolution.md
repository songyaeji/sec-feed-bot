# PamStealer macOS 멀웨어 C2 암호화 및 지속성 강화

macOS 정보탈취 멀웨어 **PamStealer**의 새 버전이 발견됐다. 주요 페이로드를 서버 측 해독 체인으로만 복원 가능하도록 암호화하고, 다층 지속성 메커니즘을 추가했다. 여전히 JavaScript for Automation(JXA) 드로퍼를 사용하지만 유혹 방식과 전달 방법은 개선했다.
